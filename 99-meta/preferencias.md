# Preferencias de trabajo

## Comunicación
- Nunca usar emojis, en nada.
- Explicaciones breves y precisas, salvo que pida más detalle.
- Para conceptos nuevos, usar analogías.

## Código
- Lenguajes preferidos: Python y React. FilamentPHP para dashboards rápidos.
- Diagnosticar primero; preferir snippets puntuales antes que reescrituras completas.
- Backend: priorizar APIs y comunicación entre microservicios.

## Diseño
- UI/UX prioritaria: profesional, minimalista, moderna y sobre todo funcional.

## Entregables
- Preferir formatos compatibles con Manus (.skill o .zip).
