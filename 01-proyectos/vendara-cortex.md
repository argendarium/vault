# Ecosistema Vendara / Cortex

## Resumen
Ecosistema POS y SaaS bajo la marca Cortex/Vendara (Quisqueya Network IRL). Nunca se lanzó comercialmente. Se construyó con Claude Code y Manus.im como agentes.

## Componentes
- Vendara Fiscal: cumplimiento e-CF dominicano; concepto de módulo de formalización (ONAPI, Cámara de Comercio, DGII, TSS).
- CortexPayTax: SaaS de facturación electrónica e-CF. Análisis competitivo contra Softland, QuickBooks, Alegra y FacturasRD de cara al mandato e-CF de noviembre 2026.
- Cortex Library: gestión documental B2B con LLM local (Ollama), OCR (PaddleOCR) y búsqueda semántica (pgvector).
- Relacionados: [[atm-tracker]], [[vendara-agro]].
